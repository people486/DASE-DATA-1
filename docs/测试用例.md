## 浏览器手工验收步骤

下列步骤提供给提交者复核；未执行的人工操作不得填写“已通过”。

1. 启动服务，使用两个浏览器配置文件分别注册作者A和填写者B；确认列表只显示本人问卷。
2. A创建允许匿名、禁止重复、未来截止的问卷。先加单选q1，再加多选q2、数字q3、文本q4。先将各题应用到草稿，再用可视化跳转编辑器添加q1到q3、q2到q4、q3到END规则，参考API说明或演示问卷。
3. 发布并复制链接，B打开。输入不合法答案，检查页面错误提示；选否跳q3，填20，再填写文本并提交。A查看统计，数字回答数1、平均20。
4. B再打开链接，尝试提交，检查禁止重复提示。A关闭问卷，B刷新链接检查关闭提示。
5. 新建允许重复问卷，B匿名连续提交年龄20、40；A统计平均30。检查单题筛选、文本内容、多选次数。
6. 创建短截止问卷，截止后刷新及提交均应被拒绝。打开两个管理标签页保存同一草稿，第二个过期版本应报冲突。

预期页面输出：登录页、本人列表、题目编辑器、当前适用题、错误信息、提交成功编号、整卷或单题统计。人工实际结果由执行者补充；自动测试不冒充页面人工验收。
